## Tiếng Việt
Script tự động hóa: flash qua UART (xmdm), build hybrid image, verify sau flash.

## English
Automation scripts: UART/xmdm flashing, hybrid image construction, post-flash verification.

- `xflash12.py` — rescue staging + jump
- `phaseE.py` — NAND write + UBI write + verify
- `build_hybrid8.py` — 2RDH hybrid packager
- `postflash_verify.py` — validation
- `autoflash9.sh` — chained runner
- `fdt_dump.py` — FDT inspection
